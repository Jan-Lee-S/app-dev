# 🪓 My Favorite Anime: Vinland Saga

This repository is created for my Application Development task performance. Below is a detailed overview of my favorite historical action anime series.

## 📌 General Information
* **Genre:** Historical, Action, Drama, Epic
* **Author:** Makoto Yukimura
* **Studios:** WIT Studio (Season 1) / MAPPA (Season 2)

## 👥 Main Characters
1. **Thorfinn** - A young warrior driven by revenge who seeks true peace.
2. **Askeladd** - A cunning and charismatic Viking band leader.
3. **Canute** - A young prince who undergoes a massive transformation to build a utopia.
